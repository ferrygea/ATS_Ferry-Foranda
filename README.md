## Spesifikasi Program

- **Classifier**: Support Vector Machine (SVM)
- **Metode Evaluasi**: Leave-One-Out-Cross-Validation (LOOCV)
- **Metrik Evaluasi**: Confusion Matrix, Accuracy, Precision, F1-Score
